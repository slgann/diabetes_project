Section: Select and Train a Model

執行下列六個模型，每個都要訓練出結果(訓練誤差不一定要很小)。
參數可以改，請自行嘗試。

Model1線性回歸
from sklearn.linear_model import LinearRegression
lin_reg = LinearRegression()
lin_reg.fit(XXXX_features 的矩陣, XXXX_labels 的向量)

Model2決策數
from sklearn.tree import DecisionTreeRegressor
tree_reg = DecisionTreeRegressor(random_state=42)
tree_reg.fit(XXXX_features 的矩陣, XXXX_labels 的向量)

Model3隨機森林
from sklearn.ensemble import RandomForestRegressor
forest_reg = RandomForestRegressor(n_estimators=100, random_state=42)
forest_reg.fit(XXXX_features 的矩陣, XXXX_labels 的向量)

Model4支援向量機
from sklearn.svm import SVR
svm_reg = SVR(kernel="linear")
svm_reg.fit(XXXX_features 的矩陣, XXXX_labels 的向量)

Model5感知器
from sklearn.linear_model import Perceptron
per = Perceptron(max_iter=1000, tol=1e-3, random_state=42)
per.fit(XXXX_features 的矩陣, XXXX_labels 的向量)

Model6神經網路
from sklearn.neural_network import MLPRegressor
